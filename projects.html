Healthcare 30-Day Readmission Risk Predictive Model

GitHub Repository ↗ View Deployed App ↗

Problem Context & Objective

Hospital readmissions within 30 days of discharge cost healthcare providers billions annually and indicate patient care gaps. Using the Diabetes 130-US Hospitals clinical dataset, this project aimed to identify early warning signals and build predictive models to flag high-risk patients before discharge.

Handling Severe 11.2% Class Imbalance

Only ~11.2% of patient encounters resulted in a 30-day readmission. Standard accuracy was deceptive (an 89% dummy classifier). By engineering stratified validation folds and tuning cost-sensitive loss functions in XGBoost and LightGBM, the model achieved 0.5466 Recall and 0.6804 ROC-AUC.
